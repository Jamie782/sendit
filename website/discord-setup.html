DISCORD SETUP

Four steps and the SEND IT bot builds the whole server for you: channels, roles, rules, the welcome message and an invite link. Nothing to install.

1

Make an empty server

Discord doesn't let bots create servers, so this bit is yours. In Discord press + → Create My Own → For me and my friends, name it SEND IT. Leave it empty.

2

Give Supabase the bot token

  1. Open the bot page, press Reset Token and copy it. Keep it private, don't paste it anywhere else.
  2. In Supabase go to Edge Functions → Secrets, add a secret called DISCORD_BOT_TOKEN and paste it as the value.
BOT PAGE ↗ SUPABASE SECRETS ↗
3

Add the bot to your server

Pick the SEND IT server and press Authorise. It asks for Administrator so it can make the channels and roles.

ADD THE BOT ↗
4

Build it

The bot makes everything in about a minute. Safe to press again later: it updates instead of making copies.
