Where's the download for just the game?

There isn't one any more. The game now only runs from the launcher, so everyone is always on the newest version. If you have an old copy of the game on its own, get the launcher and install from there. Your account, coins and skins are saved online.

Windows says "Windows protected your PC"

That's SmartScreen being careful with new apps. Click More info, then Run anyway. You only have to do it once.

Mac says the app "is damaged" or "can't be opened"

SEND IT isn't from the App Store, so macOS blocks it the first time. Fix it once:

  1. Drag SEND IT Launcher into your Applications folder.
  2. Open Terminal, paste xattr -cr "/Applications/SEND IT Launcher.app" and press Return.
  3. Open the launcher again.
Got an invite link from a friend?

Open it and press Open in SEND IT. The game starts and joins their server. You can also type the code into Online → Join with code.
