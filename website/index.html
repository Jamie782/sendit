Windows says "Windows protected your PC"

That's SmartScreen being careful with new apps. Click More info, then Run anyway. You only have to do it once.

Mac says the app "is damaged" or "can't be opened"

SEND IT isn't from the App Store, so macOS blocks it the first time. Fix it once:

  1. Drag SEND IT Launcher (or Send It) into your Applications folder.
  2. Open Terminal and paste: xattr -cr "/Applications/SEND IT Launcher.app" then press Return (for the game on its own it's "/Applications/Send It.app").
  3. Open Send It. If it still won't open, paste codesign --force --deep --sign - "/Applications/Send It.app" and press Return, then open it again.
